# 🐢 TurtleLingo — Приложение для изучения английского

TurtleLingo — интерактивная платформа для изучения английского языка с дружелюбной черепашкой: слова, грамматические окончания, времена и контекстные упражнения.

---

## 🚀 Как запустить

### 1. Веб-приложение (графический интерфейс с современным дизайном)
Запусти в терминале:
```bash
python app.py
```
Приложение автоматически откроет браузер по адресу [http://localhost:5000](http://localhost:5000).

### 2. Telegram-бот
1. Заполни файл `.env` своим токеном от `@BotFather`:
   ```env
   BOT_TOKEN=твой_токен
   ```
2. Установи зависимости (если ещё не установлены):
   ```bash
   python -m pip install -r requirements.txt
   ```
3. Запусти бота:
   ```bash
   python bot.py
   ```

## ✨ Что нового и как учтены правки

1. **Честный тест уровня с грамматикой и окончаниями**:
   - Раньше тест оценивал уровень только по изолированным словам, из-за чего уровень случайно завышался до B2.
   - Теперь тест проверяет **грамматические окончания и формы слов**:
     - **A1**: окончания Present Simple (`-s`, `-es`), продолженное время (`-ing`), множественное число (`-es`).
     - **A2**: прошедшее время Past Simple (`-ed`, `-d`, `-ied`), сравнения (`-er`, `-est`).
     - **B1**: 3-я форма Past Participle в Present Perfect (`have finished`), наречия (`-ly`), герундий после предлогов (`-ing`).
     - **B2**: продвинутые суффиксы существительных и прилагательных (`-ment`, `-able`, `-ence`), деепричастные обороты (`Having done`).
   - Если пользователь не набирает уверенные баллы на этапе A2 или B1, тест не завышает уровень до B2, а точно фиксирует **A2** или **B1**!

2. **Два режима ответа: выбор вариантов и ввод «от руки»**:
   - **Варианты ответов**: 4 удобные большие кнопки в стиле Duolingo.
   - **Ввод от руки**: текстовое поле ввода прямо под вопросом. Можно ввести окончание (например: `-ed`, `ed`, `s`) или полную форму слова (`watched`, `works`, `fluently`).
   - В Telegram-боте также поддерживается ввод от руки: пользователь может просто написать ответ текстом в чат!

3. **Убраны лишние обещания хвалить**:
   - Текст *"а я буду тебя хвалить 💚"* полностью удалён из приветствий и сообщений. Обратная связь теперь нейтральная, естественная и полезная (показывает конкретные правила и объяснения).

4. **Современное веб-приложение (`app.py`)**:
   - Приятный зелёный дизайн в стиле Duolingo.
   - Вкладки: **Учиться** (уроки), **Тест уровня**, **Словарь и правила**, **Профиль**.
   - Озвучка английских слов и предложений кнопкой 🔊.
   - Звуковые эффекты (Web Audio API) и праздничное конфетти при завершении уроков и тестов.
   - Кнопки быстрой ручной смены уровня в профиле (**A0**, **A1**, **A2**, **B1**, **B2**).
   - Единая база данных `turtlelingo.db` (прогресс синхронизирован между ботом и веб-приложением).

## ☁️ Деплой на Railway

Всё уже подготовлено: `start.sh` (веб + бот одним сервисом), `railway.json`, чтение `PORT`/`DB_PATH`/`HOST` из окружения, автоотключение SSH-туннеля на хостинге.

### 1. Сервис

1. [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo** → этот репозиторий.
2. Railway сам поставит зависимости из `requirements.txt` и запустит `bash start.sh` (из `railway.json`).

> **Почему один сервис, а не два.** Бот и веб-приложение пишут в **один** `turtlelingo.db`.
> Volume в Railway подключается только к одному сервису, поэтому два отдельных сервиса
> получили бы две разные базы — прогресс бы расходился. `start.sh` поднимает оба процесса
> в одном контейнере, база общая, при падении любого процесса сервис перезапускается целиком.

### 2. Volume для базы (иначе прогресс стирается при каждом деплое)

**Service → Volumes → Add Volume**, Mount Path: `/data`.

Затем в **Variables**: `DB_PATH=/data/turtlelingo.db`.

### 3. Переменные (вкладка Variables)

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от `@BotFather` |
| `DB_PATH` | `/data/turtlelingo.db` |
| `WEBAPP_URL` | `https://<домен>.up.railway.app` — заполнить после шага 4 |

`PORT` и `HOST` задавать не нужно: порт даёт Railway, `HOST=0.0.0.0` уже дефолт.
Туннель `localhost.run` на сервере не нужен и отключается автоматически (`DISABLE_TUNNEL`).

### 4. Домен

**Settings → Networking → Generate Domain** → скопировать `https://....up.railway.app` →
вписать в `WEBAPP_URL` → **Redeploy** (бот при старте ставит кнопку WebApp в Telegram).

### 5. Проверка

- открыть `https://<домен>.up.railway.app` — интерфейс должен ответить;
- в Telegram нажать кнопку **Приложение** — откроется Mini App;
- пройти урок в вебе и в боте — прогресс должен совпадать (одна база).

### Локально

Всё как раньше: `python app.py`, `python bot.py` — `settings.py` по умолчанию
поднимает `127.0.0.1:5000` и включает туннель, потому что `PORT`/`RAILWAY_*` не заданы.

### Если что-то не поднялось

| В логах | Причина | Что делать |
|---|---|---|
| `❌ BOT_TOKEN не задан` | нет переменной `BOT_TOKEN` | Variables → `BOT_TOKEN=<токен>` → Redeploy. `.env` на сервере не нужен и в git его класть нельзя |
| `Не найден BOT_TOKEN` (старый текст) | то же самое | то же самое |
| `⚠️ DB_PATH не задан` | нет Volume | Volumes → Add Volume, Mount Path `/data`; Variables → `DB_PATH=/data/turtlelingo.db` |
| `Application failed to respond` | сервис не слушает `PORT` | проверить, что Start Command = `bash start.sh` (из `railway.json`) |
| Кнопка WebApp ведёт на мёртвый `*.lhr.life` | не задан `WEBAPP_URL` | Variables → `WEBAPP_URL=https://<домен>` → Redeploy |
| `bot: 401 Unauthorized` | токен отозван/с опечаткой | перевыпустить у `@BotFather`, обновить `BOT_TOKEN` |

### Оговорки
- `app.py` — стандартная библиотека (`http.server`), **Flask не нужен**; в `requirements.txt` только `requests`.
- `http.server` — учебный сервер, без graceful shutdown и лимитов; для лабораторной ок, для продакшена взяли бы WSGI-сервер.
- SQLite на Volume — одна база на оба процесса, запись последовательная; при высокой нагрузке лучше Postgres.
