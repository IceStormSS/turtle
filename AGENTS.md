# AGENTS.md — правила работы с этим репозиторием

## Коммиты

- **Всегда коммить результат, если изменение получилось и работает.**
  Как только фича/фикс заработал (проверено запуском, тестом или ручной проверкой) — сразу делать `git commit`.
- Формат сообщений: `<область>: <что сделано>` (например `bot: fix level test rounding`,
  `web: add level switch buttons`). Описание — по-английски, коротко и по делу.
- Один коммит = одна законченная, рабочая логическая единица. Незаконченное и сломанное не коммитить.
- После коммита пушить в `origin main`, если пользователь не сказал обратного:
  `git push origin main`. Не пушить только если явно просили «пока не пушь».
- Не «улучшать» незаметно попутный код: если правка требует затронуть чужой код — делать отдельным коммитом.

## Безопасность репозитория

Никогда не коммитить и не пушить:
- `.env` — реальный `BOT_TOKEN` (в репо только `.env.example`)
- `*.db` — локальная база `turtlelingo.db`
- `cloudflared.exe` — бинарь ~55 МБ
- `__pycache__/`, `venv/`
- любые токены, ключи, пароли и временные ссылки туннелей

Перед коммитом проверять `git status --short` и `git diff --cached --name-only`.

## Проверка перед коммитом

- Python: `python -m py_compile app.py bot.py grammar.py words.py tunnel.py`
- Веб: запуск `python app.py` и проверка http://localhost:5000 (главная + вкладки Учиться / Тест уровня / Словарь / Профиль).

## Структура

- `app.py` — Flask-веб (порт 5000), `templates/index.html`, `static/style.css`, `static/app.js`
- `bot.py` — Telegram-бот, `grammar.py` / `words.py` — данные и логика упражнений
- `tunnel.py` — поднимает cloudflared-туннель и пишет URL в `webapp_url.txt`
